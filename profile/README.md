## What is Open RotMG?

Open RotMG is an authentic, one to one recreation of Realm of the Mad God as it was in 2012. No custom content, no donations, all open source. Development is at a hobbiest pace, but we welcome all contributors.

We host a community server for people to enjoy the game and find bugs. If you want to help, come by our Discord to chat with us. We don't bite! :)
